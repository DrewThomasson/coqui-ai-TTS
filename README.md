# OmniVoice integration samples

Audio generated locally from the implementation proposed in
[idiap/coqui-ai-TTS#587](https://github.com/idiap/coqui-ai-TTS/pull/587), using
the official `k2-fsa/OmniVoice` checkpoint on Apple M1 Pro/MPS.

- `automatic-voice.m4b`: automatic voice selection
- `designed-voice.m4b`: voice design with `male, british accent`
- `cloned-voice.m4b`: voice cloning from the automatic-voice sample

All files are mono AAC audio in an M4B container at 24 kHz.
